# Datos locales del agente de fitness

Los registros reales (`diario/`, `medidas/`, `resumenes/`) no se versionan.
Copia ejemplos así:

```bash
cp fitness-agent/data/ejemplos/2026-09-14.json fitness-agent/data/diario/
cp fitness-agent/data/ejemplos/2026-09-15.json fitness-agent/data/diario/
cp fitness-agent/data/ejemplos/medidas-2026-09-08.json fitness-agent/data/medidas/2026-09-08.json
```
